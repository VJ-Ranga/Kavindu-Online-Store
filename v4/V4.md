# Kavindu Online Store — v4 brief (simplified, final-candidate)

Base: v4 is a copy of v3 (read v3's SPEC.md for WooCommerce markup rules, page list, KV API). This file OVERRIDES v3 where different.

## Audience & purpose (client direction 2026-10-21)
Day-to-day Sri Lankan families buying fridges, TVs, washing machines, furniture — often on monthly Easy Payment. Not premium shoppers.
Site must be: traditional retail (like Damro / Singer / Abans) with a light modern, clean touch; professional; easy to understand; fast on normal mobile internet.
NOT: minimal all-white, flashy, AI-trendy, many colours. NO gradients/blobs/glass/emoji.
Shop staff must update it easily → **banners are IMAGE-ONLY slots** (staff design one image with text/price baked in, upload, set link). No HTML text over banners.

## Colours (fixed — only these)
Primary blue #1C6FB0 (hover #155A91) · Navy #16213A (top bar, header band option, footer) · Page bg #FFFFFF with light grey bands #F4F6F8 ·
Text #1F2937, muted #5B6573, border #E3E6EA · Sale red #C62828 (sale badge/price only) · Easy Payment green #1F8A5B (finance text/badges only) · Star #E8A317.
Font Poppins 400/500/600. Radius: 8px cards & banners, 6px buttons/inputs, 999px only for search field. Light shadow only on hover/dropdowns.
Remove the "Design style / skin" option and all `body[data-skin="2"]` CSS — one design only.

## Banner system (image-only)
`KV_DATA.banners` (in assets/js/data.js) — each slot = `{ img, imgMobile (optional), link, alt }`:
```
banners: {
  heroSlides:  [ {img, imgMobile, link, alt} x3 ],   // desktop 1320x520, mobile 800x800
  heroSide:    [ {img, link, alt} x2 ],              // 640x252 each (stacked beside slider)
  promoRow:    [ {img, link, alt} x3 ],              // 424x220 each (3-across row mid-page)
  wideBanner:  {img, imgMobile, link, alt},          // 1320x200, mobile 800x400 (Easy Payment / delivery strip)
  furniture:   {img, link, alt}                      // 640x560 tall feature banner beside furniture products
}
```
Sample images live in `assets/img/banners/*.webp` (generated from HTML templates in `banner-src/`, rendered by the lead).
Filenames: hero-1.webp hero-2.webp hero-3.webp, hero-1-m.webp hero-2-m.webp hero-3-m.webp, side-1.webp side-2.webp, promo-1.webp promo-2.webp promo-3.webp, wide-easy.webp wide-easy-m.webp, furniture.webp.
Rendering: `<picture><source media="(max-width:767px)" srcset="imgMobile"><img src="img" width height alt loading=lazy (eager+fetchpriority=high for first hero) decoding=async></picture>` wrapped in `<a href=link>`. Banners keep exact aspect ratio (aspect-ratio CSS) so no layout shift; radius 8px; no text overlay; slider = simple vanilla fade/slide with arrows + dots, autoplay 5s, pause on hover/focus, respects reduced motion.

## Homepage order (v4)
promo bar (one line, dismissible) → header → hero (layout option, image slots) → service strip (Islandwide delivery · Easy Payment up to 36 months · Genuine warranty · Showrooms) → categories → Best sellers → promoRow (3 image banners) → Deals this week → wideBanner (Easy Payment image) + short Easy Payment calculator band (keep v3's, compact) → furniture: tall banner + New arrivals grid/carousel → brands row (text logos) → footer.
Remove: buying guides section, showroom strip duplicates if redundant.

## Performance (normal internet)
Images: width/height attrs, loading=lazy below fold, Unsplash URLs w=600 for cards (w=1200 max elsewhere), banners WebP < 120KB. Max one font family 3 weights with display=swap; preconnect fonts + images.unsplash.com. No new libraries. Defer scripts. No layout shift.
